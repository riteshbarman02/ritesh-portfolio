# APL Cricket Timeline Prediction

APL Timeline Prediction is a real-time cricket alternate reality simulation engine. It allows users to visualize, tweak, and simulate different branching match timelines by injecting custom tactical decisions (e.g., changes in batsman strategy, bowler rotations, or aggressive field placements) and analyzing how they affect match outcomes using Google Gemini AI.

---

## 🌟 Key Features

* **Interactive Node Graph:** Visualize match progression nodes using `React Flow`.
* **Branching Timelines:** Create "what-if" alternate realities for historical matches and compare final scores.
* **Gemini AI Simulation:** Leverage generative models to predict the exact commentary, run-rate, and wickets based on tactical adjustments.
* **Real-time Analytics:** Modern analytics dashboard built with chart libraries to show run progression overlays.
