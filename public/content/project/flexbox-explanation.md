# CSS Flexbox Explanation & Playground

An educational utility to assist developers in mastering flexbox page layouts. It provides sliders and dropdowns to dynamically control flex attributes on boxes and visualize lines and alignment bounds.

---

## 🌟 Key Features

* **Visual Sandbox:** See alignment properties (`justify-content`, `align-items`, `flex-wrap`) update on dummy grid cells immediately.
* **Child Prop Tweakers:** Independently edit individual flex item values (`flex-grow`, `flex-shrink`, `flex-basis`, `order`).
* **Clean Code Generators:** Click a button to copy clean CSS styles matches your playground parameters directly.
* **Responsive Layout:** Sandbox adapts to show stacked or inline mobile preview configurations.
