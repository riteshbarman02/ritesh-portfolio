# QuickQuiz Web Game

QuickQuiz is a responsive trivia game featuring custom multiple choice questions, timer countdowns, interactive scoreboards, and persistent local high score tracking.

---

## 🌟 Key Features

* **General Knowledge Trivia:** Categorized question databases with automated correct-answer scoring.
* **Persistent Leaderboards:** Uses the browser's `localStorage` API to save top scores across gaming sessions.
* **Timed Challenges:** Dynamic CSS loaders matching active countdown timers to push user responses.
* **Feedback System:** Immediate color shifts (green for correct, red for incorrect) providing visual cues.
