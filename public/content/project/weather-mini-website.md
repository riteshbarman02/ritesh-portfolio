# Weather Forecast Mini Website

An elegant weather search dashboard fetching forecast details globally by query, integrating OpenWeather dynamic REST APIs.

---

## 🌟 Key Features

* **Real-time API Fetching:** Fetches live weather conditions using asynchronous client-side promises.
* **Dynamic Icons:** Layout backgrounds and weather icons shift depending on localized conditions (sunny, rainy, snow, cloud).
* **Comprehensive Stats:** Shows detailed statistics overlays: wind speed, humidity indexes, atmospheric pressures, and min/max ranges.
* **Compact Layout:** Perfect single-card design suited for desktop widgets and mobile web views.
